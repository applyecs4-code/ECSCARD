APPLY ECS - Netlify + Supabase (v5 full, fixed)

3 STEPS TO DEPLOY (one time only):

1) SUPABASE -> SQL Editor -> New query -> paste the whole content of run_all.sql -> Run
   (Creates the Cart, Live, Blogs and enquiry-cart link tables. Safe to run again.)
   If the admin panel ever shows a "table not found / schema cache" error, it has a "Copy SQL" button right there.

2) NETLIFY -> Site configuration -> Environment variables. Add these (Netlify does not read the .env file):
   SUPABASE_URL, SUPABASE_SERVICE_KEY, SESSION_SECRET
   SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASS, MAIL_FROM     <- emails will not be sent without these
   Then Deploys -> Trigger deploy -> Clear cache and deploy.

3) Push this folder to GitHub. Do NOT push .env (it is in .gitignore). Drag-and-drop deploy will not work.

LOCAL TEST:
   node scripts/build.mjs
   npx netlify-cli dev        -> http://localhost:8888/admin/

Admin: https://your-site/admin/   -> The Blogs tab has 10 draft blogs; use "Make live" to publish them.
